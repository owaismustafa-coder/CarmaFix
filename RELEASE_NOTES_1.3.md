# Carma Fix 1.3 — Carma AI + Liquid Glass UI

- Added Carma AI conversational assistant with vehicle/job context.
- Added quick prompts for symptoms, estimates, tracking and safety questions.
- Added safety-aware local fallback responses for critical vehicle symptoms.
- Added backend-ready AI proxy adapter via `EXPO_PUBLIC_AI_PROXY_URL`; no AI secret is stored in the mobile app.
- Added Liquid Glass-inspired cards and surfaces using `expo-blur` on iOS with a stable translucent fallback on Android.
- Added Light, Dark and System appearance modes with persistent preference.
- Refreshed Dashboard, Services, Jobs, Map and Settings with glass surfaces, ambient gradients and adaptive colors.
- Added Carma AI entry points from Dashboard, Services, Map and Settings.
- Updated package version to 1.3.0 and retained Expo SDK 54 / EAS setup.
