# Carma Fix UI Design System — v1.1

## Visual direction
Modern UAE mobility-tech: calm, premium, reassuring and operationally clear. Avoid the visual language of a traditional workshop. The customer should feel they are using a trusted mobility concierge.

## Core colors
- Carma Green: #0B8F68
- Deep Green: #056449
- Charcoal: #15221E
- Canvas: #F4F7F5
- White: #FFFFFF
- Soft Mint: #E5F6EF
- Warning: #FFB84D
- Blue Utility: #4378E8

## Core reusable widgets
- BrandMark: placeholder app/brand icon
- Card: main elevated surface
- Pill: state chips / statuses
- QuickAction: roadside service shortcut
- Metric: dashboard KPI / vehicle-health widget
- ProgressBar: service progress state
- SectionTitle: section heading/action pattern

## Data placeholders ready for APIs
- Recovery ETA
- Recovery driver name, rating and vehicle registration
- Garage name and location
- Vehicle mileage and health
- Next service distance
- Current service progress
- Cost estimate
- Service history
- Payment methods
- Membership / roadside-plan state
- Push notification state

## Production replacements
Replace the mock values with backend data without changing the layout contracts. Map pins, garage cards, driver cards, health widgets and payment summaries are intentionally component-like placeholders for API integration.
